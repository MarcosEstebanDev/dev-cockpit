# dev-cockpit · Módulo 1 (Bitácora) — Plan de implementación

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** App de bandeja en .NET/Avalonia que junta commits propios y notas rápidas y genera la daily, el semanal y la lista de logros, con IA local opcional.

**Architecture:** Hexagonal: `Core` (dominio, puertos, servicios puros), `Infrastructure` (git por CLI, SQLite, JSON, proveedores de IA por HTTP, Credential Manager), `App` (Avalonia + CommunityToolkit.Mvvm, bandeja, atajo global). El núcleo no conoce IO; todo se prueba con xUnit.

**Tech Stack:** .NET 10 (SDK 10.0.403), C#, Avalonia 12, CommunityToolkit.Mvvm, Microsoft.Data.Sqlite + Dapper, SharpHook, Microsoft.Extensions.DependencyInjection, xUnit.

**Spec:** `docs/superpowers/specs/2026-11-07-dev-cockpit-design.md`

## Global Constraints

- Se corre en la PC personal de Marcos (Windows 10). Solo se prueba en Windows; no usar APIs exclusivas de Windows fuera de `Infrastructure/Windows/`.
- `net10.0` en todos los proyectos; `<Nullable>enable</Nullable>`, `<TreatWarningsAsErrors>true</TreatWarningsAsErrors>`.
- Git: ruta del ejecutable configurable; default `C:\Users\marcos\AppData\Local\Programs\PortableGit\cmd\git.exe` si existe, si no `git`.
- IA por defecto: **Ollama**, `http://localhost:11434`, modelo `qwen2.5:7b-instruct`. Claude y ChatGPT apagados por defecto.
- API keys solo en Credential Manager (destino `DevCockpit:<proveedor>`), nunca en el JSON de configuración ni en logs.
- Antes de enviar a un proveedor no local: mostrar el texto exacto y pedir confirmación; "no volver a preguntar" se guarda por repo.
- Atajo de nota rápida por defecto: `Ctrl+Alt+N`, configurable.
- Datos en `%APPDATA%\DevCockpit\` (`settings.json`, `devcockpit.db`).
- Idioma de los resúmenes: `Es` o `En`, elegible por resumen. Textos de la interfaz en español.
- Lunes → la daily toma el viernes; sábado y domingo → viernes.
- Sin módulos 2 y 3 en este plan (ni placeholders).

## Review Focus

1. Email con caracteres de regex (`marcos.godoy+work@mail.com`) → debe coincidir literal (`git log --author` es regex). Test en Task 3.
2. Ollama apagado o modelo inexistente → se muestra el resumen por plantilla con aviso "No se pudo usar la IA: …", sin colgarse (timeout 120 s). Test en Task 6.
3. Carpeta observada borrada o que no es repo → ese repo figura como error y los demás se incluyen igual. Test en Task 3 y Task 6.
4. Mensajes de commit con tildes/ñ/emoji → llegan intactos (forzar UTF-8 en la salida de git). Test en Task 3.
5. Abrir la app dos veces → la segunda instancia no registra otro atajo ni otro ícono; se cierra y trae al frente la primera. Verificación manual en Task 7.


```
**Hoy**
-
```

### Task 3: Lectura de commits por git CLI

**Files:**
- Create: `src/DevCockpit.Core/Ports/IGitLog.cs`
- Create: `src/DevCockpit.Infrastructure/DevCockpit.Infrastructure.csproj`, `Git/GitCliLog.cs`
- Test: `tests/DevCockpit.Infrastructure.Tests/Git/GitCliLogTests.cs` (proyecto xunit nuevo)

**Interfaces:**
- Produces:
  - `record GitLogResult(IReadOnlyList<Commit> Commits, string? Error)`
  - `interface IGitLog { Task<GitLogResult> GetCommitsAsync(WatchedRepo repo, IReadOnlyCollection<string> authorEmails, DateTimeOffset from, DateTimeOffset to, CancellationToken ct); }`
  - `class GitCliLog(string gitExecutable) : IGitLog`

Comando: `git -C <path> -c i18n.logOutputEncoding=UTF-8 log --all --no-merges --since=<from ISO> --until=<to ISO> --author=<regex> --format=%H%x1f%ae%x1f%aI%x1f%s%x1e`. Un `--author` por email, cada uno con `Regex.Escape` y anclado `<email>`. Usar `ProcessStartInfo` con `ArgumentList` (nunca concatenar) y `StandardOutputEncoding = UTF8`. Exit code ≠ 0 o carpeta inexistente → `GitLogResult([], stderr o "La carpeta no existe")`, nunca excepción. Deduplicar por SHA.

- [ ] **Step 1: Tests que fallan** (cada test crea un repo temporal con `git init` y commits con `-c user.email=… --date=…`):

  - `Email_with_regex_chars_matches_literally` (`marcos.godoy+work@mail.com` coincide; `marcosXgodoy+work@mail.com` no)
  - `Preserves_unicode_subject` (`"fix: ñandú áéí 🚀"`)
  - `Respects_date_window`
  - `Missing_folder_returns_error_not_exception`
  - `Non_repo_folder_returns_error`
